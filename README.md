# Ski Store - E-commerce Website

Responsive multi-page e-commerce website for a modern ski equipment store.

**Live Demo:** https://jedidiahodephil.netlify.app/ski-store/
**Portfolio:** https://jedidiahodephil.netlify.app

### Built With
- HTML5
- CSS3 (Flexbox, Grid, Responsive)
- JavaScript (Vanilla)
- Mobile-first design

### Pages
- Home
- Shop / Products
- Product Details
- Cart
- About / Contact

### Features
- Fully responsive on all devices
- Clean UI/UX for e-commerce
- Product listing & filtering
- Shopping cart functionality
- Cross-browser compatible
- SEO optimized
